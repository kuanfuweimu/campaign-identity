# Design Theory, Terminology & English Benchmarks

Canonical books, academic frameworks, terminology boundaries, and industry references underpinning the 6-pillar **Campaign Identity** framework.

---

## 1. Foundational Books & Academic Frameworks

| Source | Core Contribution to This Framework |
| :--- | :--- |
| **Alina Wheeler** — *Designing Brand Identity* | Separates **Brand Identity Elements** (Brandmarks, Look & Feel) from **Brand Touchpoints** (Digital & Interactive, Environments & Spaces, Print & Collateral). |
| **Irene van Nes** — *Dynamic Identities: How to Create a Living Brand* (2012) | Defines the **6 VIS Components** (`Logo`, `Typography`, `Colour`, `Graphic Elements`, `Imagery`, `Language`) and the **Fixed vs. Variable** principle. Hero mediums (Illustration, 3D, Product Photography) occupy the swappable `Imagery` slot. |
| **Dr. Martin Lorenz** — *Flexible Visual Systems* (2021) & **Karl Gerstner** — *Designing Programmes* (1964) | Formalizes the **CAA Method** (`Components → Assets → Application`): shared geometric parameters (e.g., corner radius, stroke ratio) drive typography, graphics, and UI simultaneously. Shifts deliverables from static PDFs to tools/systems. |
| **Wassily Kandinsky** — *Point and Line to Plane* (1926) & **Wucius Wong** — *Principles of Form and Design* (1993) | Grounds the `3D Forms → 2D Shapes → 1D Lines` progression in classical dimensionality (`Form` = 3D volume, `Shape` = 2D plane, `Line` = 1D path). |
| **Robert Bringhurst** — *The Elements of Typographic Style* | Establishes typographic **Ornaments** (rules, borders, corner marks, micro-symbols) as structured decorative elements distinct from functional data lines. |
| **Liliana Becerra** — *CMF Design* | Industrial design standard (**Color, Material, Finish**) bridging 3D shaders, screen texture overlays, and physical paper/print finishes. |
| **Mitch Paone (DIA Studio)** — *Time Is the Material: From Motion Branding to Kinetic Identity* & Crossmodal Research | Treats time as a primary brand material; **Crossmodal Correspondence** aligns motion parameters (`duration`, `easing`, `rhythm`) with sonic parameters (`timbre`, `BPM`, `ADSR envelope`). |

## 2. Exact Terminology Boundaries

- **Lettering vs. Typeface vs. Typography**:
  - **Custom Lettering**: Drawing bespoke letterforms for specific titles (e.g., `Game Jam`, `Chapter Zero`) as graphic lockups—not typed text.
  - **Typeface / Type Design**: Designing a full reusable font family (`A–Z`, `0–9`, weights).
  - **Typography**: Selecting typefaces and setting hierarchy, type scale, leading, tracking, and layout rhythm.
- **Scale vs. Size**:
  - **Size**: Absolute measurement (`24px`, `20mm`, `6m`).
  - **Scale**: (1) Internal proportion hierarchy (Type Scale, Spacing Scale); (2) Cross-medium adaptability across orders of magnitude—optical sizing for small type/logos, LOD for 3D/textures, responsive restructuring for viewports, and Human Scale / viewing-distance tiers for physical spaces.
- **Art Direction vs. Creative Direction vs. Design Systems / Ops**:
  - **Creative Direction**: Core premise, narrative angle, experiential concept.
  - **Art Direction**: Establishing the visual benchmark (`Master KV` & rules) and governing aesthetic consistency across disciplines (3D, social, video, spatial, web).
  - **Design Systems / Design Ops**: Codifying parameters into Tokens, Figma Libraries, AI Skills, version freezes, and cross-role workflows.

## 3. Industry Benchmarks & Public Guidelines

- **Multi-Sensory Enterprise Systems**:
  - [IBM Design Language](https://www.ibm.com/design/language/) — Philosophy, 2x Grid, Typography, Color, Motion, Sound, UI & Environmental/Spatial applications.
  - [Microsoft Fluent 2](https://fluent2.microsoft.design) — 3D materiality, depth, motion, and cross-platform UI tokens.
  - [Adobe Spectrum](https://spectrum.adobe.com) — Rigorous token taxonomy, contrast, and component state documentation.
- **3D-First & Kinetic Identity Studios**:
  - [Tendril](https://tendril.studio/work/) — 3D-first brand design systems and tactile CMF worlds.
  - [ManvsMachine](https://mvsm.com/) — 3D craft, materiality, grid-constrained typography, and audiovisual rhythm.
  - [BUCK](https://buck.co/work) — Dimensional 3D assets translating cleanly into 2D graphics and UI systems.
  - [Studio Dumbar/DEPT](https://studiodumbar.com/work) — Kinetic/motion identities scaling to stage LEDs and physical events.
  - [DIA Studio](https://dia.tv/) — Kinetic typography and time-based identity systems.
- **Critique & Research Publications**:
  - [Brand New (UnderConsideration)](https://www.underconsideration.com/brandnew)
  - [The Brand Identity](https://the-brandidentity.com)
  - [It's Nice That](https://www.itsnicethat.com)
- **2025–2026 AI-Ready Standards**:
  - **W3C DTCG `2025.10` Design Tokens Format Module** — Stable cross-tool JSON standard (`$value`, `$type`, `$description`, `{alias}`).
  - **Brand OS / Agentic Brand Guidelines** — Pairing human-readable rules (`SKILL.md` / `AGENTS.md`) with machine-readable `tokens.json` in Git repositories.
